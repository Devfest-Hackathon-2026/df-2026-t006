## 2. フォント

すべて `app/assets/fonts/` に同梱（実行時に外部から読み込まない）。日本語フォントは1つ3〜7MBと重いため、**使う文字だけに減らして（サブセット化）** 同梱している。サブセット化は改変にあたるが、SIL OFL 1.1 で認められている。予約フォント名（Noto Sans JP の 'Source'）は使っていない。
